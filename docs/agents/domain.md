# Domain docs

This repository uses one domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read the ADRs under `docs/adr/` that affect the area being changed.
- If either location does not exist, continue without treating its absence as an
  error.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md` in code, tests, issues, and
designs. Avoid synonyms that the glossary explicitly rejects. If a required
domain concept is missing, record the ambiguity instead of silently inventing a
second name.

## Decision conflicts

If a proposed change contradicts an ADR, identify the ADR explicitly and either
preserve it or add a new ADR that supersedes it.
