# Repository guidance

## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues for `dante26979-droid/PRD-Agent`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with `CONTEXT.md` at the root and system decisions under `docs/adr/`. See `docs/agents/domain.md`.
